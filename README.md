# my_website

Сайт Айдара Исаева — инженера ВК/НВК. Место, где собрано всё: услуги и контакты для заказчиков, нормативная база, инженерные калькуляторы и материалы для учеников и сотрудников.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: услуги, о себе, контакты |
| `norms.html` | Нормативные документы, обозначения систем, марки, глоссарий |
| `calc.html` | Калькуляторы: перевод расходов, напорная труба, подбор диаметра, самотёк, водопотребление |
| `learn.html` | Путь проектировщика, чек-листы ВК/НВК, памятка сотруднику, FAQ |
| `projects.html` | Портфолио объектов и собственные программы |
| `workspace.html` | Локальный учёт проектов, сроков и инженерных чек-листов |
| `404.html` | Страница «не найдено» для опубликованного сайта |
| `assets/style.css` | Общие стили (светлая/тёмная тема) |
| `assets/main.js` | Меню, переключатель темы, поиск по таблицам |
| `assets/calc.js` | Формулы калькуляторов |

Сайт статический: без сборки и зависимостей. Откройте `index.html` в браузере или запустите локально:

```bash
python -m http.server 8000
```

## Сборка публикации

Перед публикацией выполните `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Скрипт полностью пересобирает каталог `dist` из исходных страниц и папки `assets`.

## Публикация

Исходный код хранится на GitHub, а основной опубликованный адрес сайта:

`https://aidar-isaev-engineering.isaeev312.chatgpt.site`

Перед публикацией выполните сборку из предыдущего раздела. `canonical`, карта сайта, `robots.txt`, ссылки для соцсетей и страница `404` рассчитаны на этот адрес и должны изменяться вместе при переносе сайта на другой домен.

## Контент

Основные страницы заполнены готовыми формулировками: главная, нормативы, калькуляторы, обучение и проекты. Конкретные названия организаций, учебных заведений и объектов лучше добавлять только после проверки фактов.

## Рабочее место

`workspace.html` — личный журнал проектов в текущем браузере. Он хранит объекты, стадии, дедлайны, следующий шаг и чек-лист подготовки в `localStorage`; данные не отправляются на сайт и не синхронизируются между устройствами.

Регулярно используйте кнопку «Резервная копия» и храните JSON-файл в надёжном месте. Не добавляйте в этот локальный инструмент договоры, реквизиты, пароли или файлы заказчиков: для таких данных нужен отдельный защищённый кабинет с авторизацией.
